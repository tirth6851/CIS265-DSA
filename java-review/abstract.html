Abstract Classes

An abstract class cannot be instantiated; it is meant to be subclassed. It may contain abstract (no body) and concrete methods.

abstract class Shape {
    abstract double area();
    void draw() { System.out.println("drawing shape"); }}

Key points

  • Use abstract keyword before class or method.
  • A subclass must implement all abstract methods or become abstract too.
  • Can have constructors, fields, final methods.

Code Question (little code)

class Circle extends Shape { double radius; Circle(double r) { this.radius = r; } public double area() { return Math.PI * radius * radius; }}

Code Question (no code)

Can an abstract class have a final method? Answer: Yes, final methods cannot be overridden.

Practical Problems

  1. Write an abstract class Shape with an abstract method double area() and a concrete method void describe() that prints "Shape description". Create a concrete subclass Rectangle with fields width and height, a constructor, and an implementation of area().
  2. Create an abstract class Animal with a concrete method void breathe() and an abstract method void makeSound(). Provide two subclasses Dog and Cat that each implement makeSound().
  3. Demonstrate that trying to instantiate the abstract class directly results in a compile‑time error.
// Example solution for problem 1:
public abstract class Shape {
    abstract double area();
    void describe() { System.out.println("Shape description"); }
}
public class Rectangle extends Shape {
    double width, height;
    Rectangle(double w, double h) { width = w; height = h; }
    public double area() { return width * height; }
}
