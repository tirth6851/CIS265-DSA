Arrays

An array is a container that holds a fixed number of values of a single type. In Java, arrays are objects and are dynamically created.

int[] nums = {1, 2, 3, 4, 5};

Common operations

  • Declaration: int[] arr;
  • Instantiation: arr = new int[10];
  • Access: arr[2] returns the third element
  • Length: arr.length

Code Question (little code)

for (int i = 0; i < arr.length; i++) { System.out.println(arr[i]); }

Code Question (no code)

Practical Problems

  1. Write a method static int sumArray(int[] arr) that returns the sum of all elements.
  2. Write a snippet that finds the second largest element in an int array without sorting.
  3. Given an array, move all zeros to the end while preserving the order of non‑zero elements.
// Example solution for problem 1:
public static int sumArray(int[] arr) {
    int sum = 0;
    for (int v : arr) sum += v;
    return sum;
}
