Basic Data Structures

Java provides built‑in collection types for common data structures. The most used are ArrayList (dynamic array), LinkedList (double‑linked list), Stack (LIFO), and Queue (FIFO).

ArrayList list = new ArrayList<>();

Core structures

  • ArrayList – resizable array, fast random access, O(n) insert/remove in middle.
  • LinkedList – doubly‑linked list, O(1) insert/remove at ends, slower random access.
  • Stack – LIFO, methods push, pop.
  • Queue – FIFO, methods offer, poll.

Code Question (little code)

Queue q = new LinkedList<>(); q.offer("a"); String s = q.poll();

Code Question (no code)

Which interface does Stack implement? Answer: Stack extends Vector, which implements java.util.Vector; traditionally considered a legacy Stack.

Theory Question

When would you choose a LinkedList over an ArrayList? Answer: When frequent insertions/removals at ends or middle are needed.

Practical Problems

  1. Create an ArrayList of integers, add five numbers, then remove the third element and print the list.
  2. Using a LinkedList as a stack, push three strings and then pop one, printing the popped value and remaining elements.
  3. Demonstrate a Queue with a LinkedList: add two elements, poll one, and check the size.
// Example solution for problem 1:
ArrayList list = new ArrayList<>();
list.add(10); list.add(20); list.add(30); list.add(40); list.add(50);
list.remove(2); // remove element at index 2
System.out.println(list); // [10, 20, 40, 50]
