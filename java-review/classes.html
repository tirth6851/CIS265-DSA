Classes

A class is a blueprint for creating objects. It defines fields (attributes) and methods (behavior).

public class Dog {
    String name;
    void bark() { System.out.println("Woof!"); }
}

Class components

  • Fields (variables)
  • Methods (functions)
  • Constructors (initialization)
  • Nested classes

Practical Problems

  1. Write a Rectangle class with fields width and height, a constructor, and a method area() that returns the area.
  2. Define a class Book with a title field and a toString() method that returns the title.
  3. Create a generic pair class Pair with fields key and value, a constructor, and getter methods.
// Example solution for problem 1:
public class Rectangle {
    double width, height;
    Rectangle(double w, double h) { width = w; height = h; }
    double area() { return width * height; }
}
