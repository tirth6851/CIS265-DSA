Code Questions

Answer these questions. Some require a short code snippet, others are conceptual.

  1. Arrays: Write a loop to find the maximum element in an int array.
  2. Objects: Create a class Book with title and author fields, a constructor, and a method to display info.
  3. Classes: Override the toString method in a Person class to return "Name: ".
  4. OOP Thinking: Explain encapsulation in your own words (no code).
  5. Inheritance: Write a subclass Horse that extends Animal and adds a method run().
  6. Exceptions: Write a try‑catch to handle NumberFormatException when parsing a string to int.
  7. Abstract Classes: Provide an abstract class Animal with abstract method makeSound(), and a concrete subclass Dog that implements it.
  8. Recursion: Write a recursive method to compute the nth Fibonacci number.
  9. Generics: Write a generic method to swap two elements in an array.
  10. Basic Data Structures: Add and remove an element from a LinkedList.
  11. Sets: Write code to check if a Set contains a specific element.
  12. Maps: Write code to compute a mapping if the key is absent using computeIfAbsent.
