Generics

Generics enable types (classes and interfaces) to be parameters when defining classes, interfaces, and methods. Provide compile‑time type safety.

List list = new ArrayList<>();

What does the diamond operator (<>) do when instantiating a generic class? Answer: It lets the compiler infer the type argument from the left‑hand side.

Practical Problems

  1. Write a generic method public static T getMax(T[] arr) that returns the maximum element, assuming T implements Comparable.
  2. Create a generic class Box with a field T item, a setter setItem(T) and a getter getItem().
  3. Write a simple generic interface Pair with methods K getKey() and V getValue(), and provide a lambda expression that creates a Pair instance.
// Example solution for problem 1:
public static > T getMax(T[] arr) {
    T max = arr[0];
    for (int i = 1; i < arr.length; i++) if (arr[i].compareTo(max) > 0) max = arr[i];
    return max;
}

// Example solution for problem 2:
public class Box {
    private T item;
    public void setItem(T item) { this.item = item; }
    public T getItem() { return item; }
}
