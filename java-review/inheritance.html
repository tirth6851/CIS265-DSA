Inheritance

Inheritance lets a class (subclass) acquire fields and methods of another class (superclass). Java supports single inheritance for classes, but multiple interface implementation.

class Animal { void eat() { System.out.println("eating"); } }
class Dog extends Animal { void bark() { System.out.println("barking"); }}

Key points

  • Use extends keyword.
  • Subclass can override superclass methods.
  • Constructor chaining: super() call.

Code Question (little code)

@Override void eat() { System.out.println("dog food"); }

Code Question (no code)

What is the purpose of the final keyword when applied to a class? Answer: Prevents the class from being subclassed.

Theory Question

Practical Problems

  1. Create a superclass Vehicle with a field String color, a constructor, and a method void drive(). Create a subclass Car that overrides drive() to print "Car driving".
  2. Add a subclass ElectricCar that extends Car and adds a method void charge(). Demonstrate constructor chaining with super().
  3. Using an Animal superclass and a Dog subclass (as in earlier topics), show how to call super.eat() from the overridden method.
// Example solution for problem 1:
public class Vehicle {
    String color;
    Vehicle(String c) { color = c; }
    void drive() { System.out.println("Vehicle driving"); }
}
public class Car extends Vehicle {
    Car(String c) { super(c); }
    @Override void drive() { System.out.println("Car driving"); }
}
