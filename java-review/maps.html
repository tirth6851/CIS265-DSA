Maps

A Map stores key‑value pairs; each key is unique. Common implementations: HashMap (O(1) operations), LinkedHashMap (preserves insertion order), TreeMap (sorted keys).

Map map = new HashMap<>();

Key operations

  • Put: map.put("one", 1)
  • Get: map.get("one")
  • Contains key: map.containsKey("one")
  • Remove, size, clear

Code Question (little code)

Map m = new HashMap<>(); m.put("height", 180); int h = m.get("height");

Code Question (no code)

What does the computeIfAbsent method do in Map? Answer: If the key is not present, compute a value using the given function and put it into the map.

Theory Question

Compare HashMap and TreeMap regarding ordering and performance.

Practical Problems

  1. Create a HashMap, add three country‑capital pairs, retrieve the capital for a given country, and print the size.
  2. Demonstrate computeIfAbsent: if the key "population" is absent, compute a value using a lambda and put it into the map, then retrieve it.
  3. Using a TreeMap, insert a few values and iterate over the entries in sorted key order.
// Example solution for problem 1:
Map map = new HashMap<>();
map.put("USA", 1); map.put("UK", 2); map.put("India", 72);
System.out.println(map.get("USA")); // 1
System.out.println(map.size());    // 3

// Example solution for problem 2:
Map m = new HashMap<>();
m.computeIfAbsent("population", k -> 1000);
System.out.println(m.get("population")); // 1000

// Example solution for problem 3:
TreeMap tm = new TreeMap<>();
tm.put("a", 1.1); tm.put("b", 2.2);
for (Map.Entry e : tm.entrySet()) System.out.println(e.getKey() + " -> " + e.getValue());
