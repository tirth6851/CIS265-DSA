Objects

An object is an instance of a class that combines data (fields) and behavior (methods). Objects are created using the new keyword.

String s = new String("hello");

Key points

  • State is stored in fields (attributes).
  • Behavior is defined by methods.
  • Objects interact by sending messages (calling methods).

Practical Problems

  1. Write a class Employee with fields name and salary, a constructor, and a method raiseSalary(double pct) that increases salary by the given percentage.
  2. Create a Car object with a speed field and methods accelerate() and brake() that modify the speed.
  3. Given two object references, write a snippet to swap them without using a temporary variable (use XOR for primitive types or simply assign).
// Example solution for problem 1:
public class Employee {
    String name;
    double salary;
    Employee(String n, double s) { name = n; salary = s; }
    void raiseSalary(double pct) { salary *= (1 + pct/100); }
}
