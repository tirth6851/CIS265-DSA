Object‑Oriented Thinking

Thinking in objects means modelling real‑world entities as objects that encapsulate state and expose behavior through methods. Key concepts: abstraction, encapsulation, polymorphism, and inheritance.

Four pillars

  • Encapsulation – hide internal state, expose via public methods.
  • Abstraction – focus on essential features, ignore details.
  • Polymorphism – same message can behave differently on different objects.
  • Inheritance – new classes acquire properties of existing ones.

Practical Problems

  1. Define an abstract class Animal with an abstract method makeSound() and a concrete method eat(). Create a subclass Cat that implements makeSound().
  2. Write a small program that demonstrates polymorphism: assign a Cat object to an Animal reference and call both eat() and makeSound().
  3. Create an interface Drawable with method draw(), and have a class Circle implement both Animal (from previous problem) and Drawable.
// Example solution for problem 1:
public abstract class Animal {
    abstract void makeSound();
    void eat() { System.out.println("eating"); }
}
public class Cat extends Animal {
    void makeSound() { System.out.println("meow"); }
}
