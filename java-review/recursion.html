Recursion

Recursion is a method calling itself to solve a smaller instance of the same problem. Must have a base case to terminate.

int factorial(int n) { return (n <= 1) ? 1 : n * factorial(n - 1); }

Key aspects

  • Base case – condition that stops recursion.
  • Progress case – problem size reduces toward base case.
  • Stack depth – each call adds a frame; too deep may cause StackOverflowError.

Code Question (little code)

int fib(int n) { return (n <= 1) ? n : fib(n-1) + fib(n-2); }

Code Question (no code)

What is the time complexity of the naive recursive Fibonacci? Answer: O(2^n).

Practical Problems

  1. Write a recursive method int sumDigits(int n) that returns the sum of the digits of a non‑negative integer.
  2. Write a recursive method String reverse(String s) that returns the reverse of a string.
  3. Convert the recursive factorial method to an iterative version using a loop.
// Example solution for problem 1:
public static int sumDigits(int n) {
    return (n < 10) ? n : n % 10 + sumDigits(n / 10);
}

// Example solution for problem 2:
public static String reverse(String s) {
    return (s.isEmpty()) ? s : reverse(s.substring(1)) + s.charAt(0);
}
