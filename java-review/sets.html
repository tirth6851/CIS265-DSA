Sets

A Set is a collection that contains no duplicate elements. It models the mathematical set interface. Common implementations: HashSet (hash-based, O(1) operations), LinkedHashSet (preserves insertion order), TreeSet (sorted, O(log n)).

Set set = new HashSet<>();

Key operations

  • Add: set.add("a")
  • Remove: set.remove("a")
  • Check containment: set.contains("a")
  • Size, isEmpty, clear

Code Question (little code)

Set s = new HashSet<>(); s.add("a"); s.add("b"); s.add("a"); System.out.println(s.size());

Code Question (no code)

What happens if you try to insert a duplicate element into a Set? Answer: The add method returns false and the set size does not increase.

Practical Problems

  1. Create a HashSet, add the strings "apple", "banana", "apple", "cherry", then print the size and iterate to list all unique elements.
  2. Using a TreeSet, add the integers 5, 2, 8, 1 and print them in sorted order.
  3. Write a program that removes all duplicate elements from an ArrayList> by transferring them into a HashSet and back.
// Example solution for problem 1:
Set s = new HashSet<>();
s.add("apple"); s.add("banana"); s.add("apple"); s.add("cherry");
System.out.println(s.size()); // 3
for (String fruit : s) System.out.println(fruit);

// Example solution for problem 2:
TreeSet ts = new TreeSet<>();
ts.add(5); ts.add(2); ts.add(8); ts.add(1);
System.out.println(ts); // [1, 2, 5, 8]
